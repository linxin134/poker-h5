## 1. 测试架构总览

```
tests/
├── engine.test.ts                 # 引擎核心: 发牌、行动、结算、筹码守恒
├── texasHoldemRules.test.ts       # 规则合规: 行动顺序、盲注、加注、全下、边池、牌型
├── multiplayerSimulation.test.ts  # 多人模拟: 2~8人全场景、连续多手、极端场景
├── multiplayerStress.test.ts      # 压力测试: 2-9人数百手筹码守恒、嵌套边池
├── playerDynamics.test.ts         # 玩家变更: 落座、离座、补码、断线、重连、退出
├── cards.test.ts                  # 牌型评估: 10种牌型识别、比较、洗牌完整性
├── pots.test.ts                   # 底池构建: 主池/边池、弃牌贡献、零投入
├── tableLayout.test.ts            # 桌面布局: 座位坐标计算
├── audio.test.ts                  # 音频系统: 音效加载
└── uuid.test.ts                   # UUID 生成
```

**核心不变量**（贯穿所有测试）：
- **筹码守恒**: `Σ(所有玩家 stack + bet) + pot = 初始总筹码`
- **无负数**: 所有玩家 `stack ≥ 0, bet ≥ 0, totalContribution ≥ 0`
- **牌不重复**: `deck + board + 所有 holeCards` 中每张牌唯一
- **公共牌 ≤ 5**: `board.length ≤ 5`
- **手牌 ≤ 2**: 每个玩家 `holeCards.length ≤ 2`
